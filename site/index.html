Criativos

Conectar ao GitHub

Com isso, o botão “Minerar agora” dispara o robô direto daqui. O token fica salvo só neste navegador.

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha Only select repositories → seu repositório do minerador.
  3. Em Permissions → Repository → Actions, marque Read and write. Mais nada.
  4. Gere, copie e cole aqui.

Minerar pelo GitHub

  1. Abra a página do robô: Actions → Minerar ofertas.
  2. Clique em Run workflow, digite em “Tema ou palavras-chave”, escolha o país e clique no botão verde.
  3. Em ~5–10 minutos os resultados aparecem aqui (recarregue a página).

Para minerar com um clique daqui mesmo, use “⚙️ Conectar GitHub”.
